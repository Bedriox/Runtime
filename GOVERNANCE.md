# Governance

Bedriox Runtime is maintained as part of the Bedriox project. Veno Ninja LLC
controls the official repositories, releases, infrastructure, signing keys,
and project trademarks.

Technical decisions are evaluated for correctness, security, portability,
reproducibility, tests, maintainability, licensing, and project scope.
Contributions are submitted under GPL-3.0-only unless clearly stated
otherwise; bundled third-party components retain their own licenses.
